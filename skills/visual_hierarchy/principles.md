# 视觉层次 · 设计原则

设计目标：**一眼知道先看哪里**。以下五类杠杆按优先级排列，数字来自已验证的设计系统（浅底 + 单一主色 + 克制的边缘与动效）。

---

## 1 留白与间距节奏

间隔决定结构，是重排层次最快的一步。

- 基础刻度：**4px / 8px**，常用步进 `4 8 16 24 32 48 64 96`
- 大模块上下留白：`clamp(64px, 10vw, 120px)`，至少 ≥ 模块内部间距
- 内容容器宽度一致（如 `max-width:1180px`），左右对称由统一的 padding 保证
- 同组元素间距小（8-16px），组与组间距大（32-64px）→ 一眼看出分组
- 正文字行高 `1.6~1.75`，行距本身也是节奏

**规则**：宁可多留白，不要加装饰。

## 2 字号阶梯 + 字重

标题与正文的对比是第一焦点来源。

```
display  clamp(34px, 5vw, 54px)  weight 600  letter-spacing -0.045em
h2       clamp(26px, 3.5vw, 36px) weight 600  letter-spacing -0.03em
lead     17-18px         weight 400           color: muted
body     15-16px         weight 400
eyebrow  12px            uppercase            letter-spacing 0.12em  color: accen
```

- 至少 **3 档**字号阶梯，且档位间对比明显（不要 16/17/18 这种台阶）
- 大字号必须收字距（负值），小字标签必须放字距（text-transform 大写 + 0.1em+）
- 同一版面只用一个 display 字重；正文用普通字重做反衬
- 用 `text-wrap: balance` 平衡标题，`pretty` 平衡正文行尾

## 3 单一主色 + 克制辅助

色彩的职责是**高亮**，不是铺底。

- 中性灰阶至少 3 档：`ink`（正文）/ `muted`（次要）/ `border`（描边），加 `surface` 底
- 主色（accent）唯一的用途：
  - eyebrow / 高亮短语 / 链接
  - 激活态描边或边框
  - 小面积主按钮
- 主色浅面 `color-mix(in srgb, accent 8-12%, transparent)` 用于标签、链接底色
- **主色覆盖面积 ≤ 15%**；超过就减。禁止大按钮整块主色 + 深色字这种硬拼
- 深色强调区（终端/页脚）用独立深色 token，前景文字 `#f7f7f4` 一等
- 正文文本对比符合 **WCAG AA**（`contrast ≥ 4.5:1`）

## 4 边缘层级

卡片不是必须的；一旦用就要统一。

- 卡片 = `background:#fff` + `border:1px solid #e4e4e0`（或 8% 主色描边），`border-radius: 16-22px`
- 同页圆角只用 2 个值：中等（卡片 16-22）、小（按钮/标签 999 胶囊可算一种）
- 投影少而轻：`0 8px 24px rgba(0,0,0,.06)`，悬停才出现或加深
- hover 只动 1-2 个属性：`border-color → accent`、`translateY(-4px)`、`img scale(1.03)`
- 深色底板（终端）配 `#211f2d` 类深色 token + 主色命令字，形成整页最强的对比区

## 5 强调手法（五个）

1. **eyebrow**：标题上方一行小字纯色标签，预告区块主题（注意不是焦点，是用来托焦点的）
2. **聚焦词**：一句话里给关键短语 `color:accent; font-weight:600`，一行最多一个
3. **激活态隔离**：可切换列表里，"当前项"用主色边框/背景隔离，其余弱化
4. **深底亮字**：把最想让人记住的内容（作品、终端输出）放深色面板前，让白色字自带焦点
5. **数字/徽标**：平铺的内容块加序号或数据，制造秩序感

每屏只允许一个主打板（深色区/大图/强对比），其余往下压。

## 6 动效

动效放大层次，不制造乱战。

- 时长 **150-400ms**，缓动 `cubic-bezier(.2,.8,.2,1)`；位移类可略快于透明度类
- hover 只动 1-2 个属性；不要同时旋转 + 放大 + 变色
- 跑马灯/长滚动类最多 1-2 行，且必须 `duplicate` 副本循环做无缝
- 出现动画 = 轻微的 `opacity + translateY(12-16px)`，交错 `stagger 60-90ms`
- **必做** `@media (prefers-reduced-motion: reduce)`：关闭一切位移/循环，内容全部可见

## 收尾判断

每屏完成后屏住 3 秒闭眼再睁开，能回答"这一屏的重点是什么"才通过；答不出来 = 层次没立起来。
