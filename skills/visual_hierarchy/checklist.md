# 视觉层次 · 评审清单

逐项打勾后再宣布"完成"。每一项都是"否则退回去修"级别的检查。

## A 焦点

- [ ] 每个 section 只有一个主焦点（大标题 / 深色面板 / 大图，三选一）
- [ ] 其他内容为焦点让路：颜色、字号、对比全部低于焦点
- [ ] 闭眼 3 秒重看，能立刻说出首页重点

## B 间距

- [ ] 全站间隔都在 4/8px 刻度上，无 6px/10px 之类随机值
- [ ] 组内间距 < 组间间距，分组一眼可见
- [ ] 相邻模块间距不小于其内部间距
- [ ] 无"撑满"冲动——有系统性留白，且留白处不突兀

## C 文字

- [ ] 字号阶梯 ≥ 3 档，档位间对比明显（不是 16/17/18）
- [ ] 大标题：字重 ≥ 600、字距为负、有 `text-wrap: balance`
- [ ] 正文 vs 次要信息靠 muted 灰阶区分，而非靠大小硬撑
- [ ] eyebrow 用大写 + 0.1em+ 字距，颜色为 accent，且不喧宾夺主
- [ ] 单屏只有一处聚焦词（accent + 600）

## D 色彩

- [ ] 只有 1 个主色，使用面积 ≤ 15%
- [ ] 主色用于高亮/描边/激活态，未大面积铺底
- [ ] 中性灰阶 ≥ 3 档（ink / muted / border / surface）
- [ ] 全部正文对比度 ≥ 4.5:1（WCAG AA）
- [ ] 深色强调区有独立 token，前景文字用一等浅色

## E 边缘

- [ ] 全站圆角只有 2 个值（卡片 + 按钮/小元素）
- [ ] 投影少而轻，hover 才浮起
- [ ] 卡片 hover 只动 1-2 个属性，并且有 `:focus-visible` 状态
- [ ] 无多余按摩：同一层级的卡片用同一套边框/圆角/投影

## F 动效

- [ ] 时长 150-400ms，缓动一致
- [ ] 位移/透明度动画方向有含义（进入=上移淡入）
- [ ] 跑马灯行数 ≤ 2，且副本重复实现无缝循环
- [ ] `prefers-reduced-motion: reduce` 下循环型动效全部关闭、内容立即可见

## G 响应式

- [ ] 在 390px 宽下：字号/间距/焦点仍成立，无横向溢出
- [ ] 移动端焦点元素仍居首屏

## 结果

- [ ] 每屏"重点是什么"可一句话回答
- [ ] 无剩余 TODO；样式 token 统一，无散落魔法值
